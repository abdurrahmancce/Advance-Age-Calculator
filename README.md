# 🎂 Age Calculator - GUI Edition

A modern and feature-rich **Age Calculator Desktop Application** built with **Python Tkinter**.

This application allows users to calculate their exact age from a date of birth and provides detailed statistics including total months, total days, hours, minutes, zodiac sign, birthday countdown, and calculation history.

---

## ✨ Features

- 🎂 Calculate exact age in years
- 📅 Calculate total months lived
- 📆 Calculate total days lived
- ⏰ Calculate total hours and minutes
- ♈ Automatic Zodiac Sign Detection
- 🎉 Birthday Recognition & Celebration Message
- ⏳ Next Birthday Countdown
- 📁 Persistent Calculation History
- 🔄 Refresh History Anytime
- 🗑 Clear History Option
- 🌙 Modern Dark Theme UI
- 📱 Responsive Tkinter Interface
- 🕐 Real-Time Clock Display

---

## 📸 Application Tabs

### 📅 Calculator Tab

- Enter Day, Month, and Year separately
- Instant age calculation
- Detailed age breakdown
- Birthday countdown
- Zodiac sign display

### 📁 History Tab

- Stores previous calculations
- Displays calculation timestamps
- Refresh history records
- Delete all saved history
